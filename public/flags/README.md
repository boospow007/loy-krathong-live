# ASEAN flag

`asean.png` is a local copy of the ASEAN flag used for identification in the country selector and on submitted krathongs. ASEAN has no standardized flag emoji.

Source: https://commons.wikimedia.org/wiki/File:ASEAN_Flag.png
Official flag reference: https://asean.org/asean-flag/
